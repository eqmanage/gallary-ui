# 林うい アーカイブサイト(叩き台)

作家の生涯の作品をシリーズ別に公開する、非営利・非売品のアーカイブサイトです。
ビルドツールを使わないシンプルな静的サイト(HTML / CSS / JavaScript)なので、
このフォルダをそのままGitHubに置けば公開できます。

## フォルダ構成

```
index.html        トップページ(作家紹介 + コレクション一覧)
series.html       シリーズ一覧ページ(?series=シリーズID で表示するシリーズを指定)
artwork.html      作品詳細ページ(?series=...&work=... で作品を指定)
about.html        作家について・利用に関する注意書き
css/style.css     全ページ共通のデザイン(色・フォント・レイアウト)
data/works.js     作家情報・シリーズ・作品データ(★ここを編集して更新します)
js/                各ページの表示ロジック(通常は編集不要)
images/            作品画像を置く場所
```

## 1. 手元での確認方法

ダブルクリックで `index.html` を開くだけでも動きますが、ブラウザによっては
画像の読み込み等で制限がかかることがあるため、簡易サーバーを使うのが安全です。

```bash
# このフォルダの中で実行
python3 -m http.server 8000
```

その後ブラウザで `http://localhost:8000` を開いてください。

## 2. 作品を追加・編集する(プログラム未経験の方向け)

`data/works.js` を開くと、日本語のコメント付きで作品データが並んでいます。
`{ }` や `[ ]` や `,` の記号はそのままに、文字や数字の部分だけを書き換えてください。

- 既存のシリーズに作品を1点追加する → そのシリーズの `works: [ ... ]` の中に、
  他の作品と同じ形式で1行追加します。
- 新しいシリーズを追加する → `series: [ ... ]` の中に、既存のシリーズと同じ形式で
  ブロックを1つ追加します(`id` は英数字にしてください)。
- 画像を追加する → `images/` フォルダに画像ファイルを置き、その作品の
  `image: ""` の部分を `image: "images/ファイル名.jpg"` に書き換えます。
  空文字 `""` のままにしておくと「作品画像」のプレースホルダーが表示されます。

編集後は 1. の方法で表示を確認してから、GitHubにアップロードしてください。

## 3. GitHub Pagesで公開する

1. このフォルダの中身をGitHubリポジトリのルート(直下)にアップロードする
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、Branch を公開したいブランチ(例: `main`)・
   フォルダを `/ (root)` に設定して Save
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます

## 4. 複数人での共同作業の進め方

1. 各自がGitHub上でブランチを作成して作業する
   (例: `add-suiboku-images`、`fix-about-page` など内容がわかる名前で)
2. Claude Code(またはClaude)に、変更したい内容を日本語で伝えながら
   `data/works.js` の更新やページの修正を進める
3. 作業が終わったら Pull Request を作成し、他のメンバーが内容を確認する
4. 問題なければ本体のブランチ(`main`)に取り込む(マージする)

コンテンツ(文章・画像)の追加であれば `data/works.js` と `images/` の変更だけで
完結するため、プログラム未経験のメンバーでも比較的安全に参加できます。
デザインやページ構成そのものを変える場合は `css/style.css` や `js/` 内のファイル、
`index.html` などのHTMLを変更します。
